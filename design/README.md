# Design documents

`user-flow.md` shows the member, agent, Support Head, system/escalation, and status lifecycle flows. `database-erd.md` shows the frozen database schema and relationships.

GitHub renders Mermaid blocks natively. In VS Code, install a Markdown Mermaid preview extension, or paste a block into [mermaid.live](https://mermaid.live).

Frozen after Day 2. Later changes go in new files (`*-v2.md`).
